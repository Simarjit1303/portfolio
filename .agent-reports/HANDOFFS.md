### Item 1: THREE.Clock Deprecation — Upgrade @react-three/fiber

**Priority:** Low (cosmetic warning, no functional impact)

**Background:**
`@react-three/fiber` v9.5.0 uses `new THREE.Clock()` in its internal store (line 972 of `events-5a94e5eb.esm.js`). THREE.js r0.175+ deprecated `THREE.Clock` in favour of `THREE.Timer`. This produces a console warning on every page load:

```
THREE.THREE.Clock: This module has been deprecated. Please use THREE.Timer instead.
```

**Root cause location:**
`node_modules/@react-three/fiber/dist/events-5a94e5eb.esm.js:972`

**Recommended action:**
Check whether a newer version of `@react-three/fiber` (v9.5.x or later) has patched this. If so, upgrade:

```bash
npm install @react-three/fiber@latest
```

Then verify:
1. The deprecation warning is gone from browser console
2. The robot model still renders and animates
3. Cursor tracking still works (useFrame delta must still be valid)
4. No TypeScript errors

**Do NOT** attempt to patch `THREE.Clock` out of r3f manually by replacing the store clock — `THREE.Timer` has an incompatible API (no `.elapsedTime`, `.oldTime`, `.start()`, `.stop()`) and would break the render loop.
